# <IconSparkles/>AI Assistants

Connect an AI assistant to your harness.design account and it can work on your harnesses with you — look one up, explain how it's wired, add connectors and wires, assign parts, and answer questions about how the software works. Anything it changes appears in your editor **live**, while you watch.

The connection uses **MCP** (Model Context Protocol), the standard way an AI assistant connects to an outside service. harness.design runs an MCP server, so any assistant that speaks MCP can connect to it.

Set it up from <IconMenu2/>**Main Menu** → <IconAdjustments/>**Preferences** → <IconSparkles/>**AI**.

<Callout>
  The assistant signs in **as you**, so it sees exactly the harnesses you see — your own, plus any
  shared with you or belonging to your team. It can never reach anyone else's work.
</Callout>

## Connecting an assistant

Open <IconAdjustments/>**Preferences** → <IconSparkles/>**AI** and expand the assistant you want to connect. Each one shows whether it's currently **Connected**, along with the steps to set it up.

Wherever an assistant asks for the **MCP server URL**, use:

```
https://app.harness.design/mcp
```

## Starting a session on a harness

Once an assistant is connected, an **Edit with …** entry appears for it in the <IconMenu2/>**Main Menu**. Choosing it opens that assistant with the harness you're currently working on already loaded, ready for your first question.

For assistants with a desktop app (currently Claude), a **Open in Browser / Open in Desktop app** switch in the AI preferences controls which one that entry opens.

You don't have to start from the menu. You can also just ask the assistant directly — "list my harnesses", or "open my Engine Bay harness" — and it will find it.

## What an assistant can do

**Find and explain**

- List the harnesses you have access to and open one by name.
- Summarise a harness — how many connectors, wires and parts, and what's connected to what.
- Trace **nets** (everything electrically joined, through splices and mates), report computed **wire lengths**, and produce a **bill of materials** with quantities and prices.
- Answer questions about a specific component or a specific connector cavity.

**Edit**

- Add, change and remove connectors, terminals, wires, cables, twisted wires, splices, diodes, resistors, bundles, mates, groups and notes.
- Wire things together, set signals and cavity designations, and position components on the schematic and layout.
- Assign parts, and create parts it doesn't find — including looking up a real part you name by part number.
- Clean up after itself: deleting a component also removes the wires, mates, bundles and group memberships that pointed at it.

**Parts library**

- Search your parts library and reuse a part that already exists rather than inventing a new one.
- Compare the parts in a harness against your library to see what's out of sync.
- Add parts to your shared library — but only when you explicitly ask it to. By default new parts go into the harness you're working on.

**Revisions**

- List your existing revisions, and create a checkpoint before a big change when you ask for one.
- Restore a revision if you want to roll back.

**Documentation**

- Answer questions about how to use harness.design by reading these documentation pages.

<Callout>
  Everything an assistant writes goes through the same validation and the same plan limits as the
  editor. On the **Free** plan the 100-connection limit per harness still applies, and creating
  revisions still requires **Pro**.
</Callout>

## Working with an assistant

A few things that make a real difference to the results:

- **Name components the way the editor does.** Component IDs like `C1`, `W3` and `S2` are exactly what the assistant uses to find things, so "change W12 to blue" or "what's connected to C4 pin 7?" lands precisely.
- **Say which harness**, or say "the harness I have open" — the assistant can see which one you're working on and will confirm the name back to you.
- **Ask for a checkpoint before a big change**: "create a revision first, then rewire the ground circuit." It won't create one unless you ask.
- **Be specific about parts.** If you name a real part number, the assistant will look it up and create a part matching the actual specification. If you don't, it follows whatever convention the rest of the harness already uses.
- **Watch it work.** Because changes appear in the editor live, you can see each one land. If you don't like a change, <IconArrowBackUp/>**Undo** works exactly as it does for your own edits.

## While an assistant is editing

When a connected assistant starts changing a harness you have open, an indicator appears in the editor bar — for example **Claude is editing this harness…** — so you always know when a change isn't yours. It clears itself shortly after the assistant finishes.

## Disconnecting

In <IconAdjustments/>**Preferences** → <IconSparkles/>**AI**, expand the assistant and click <IconPlugConnectedX/>**Disconnect**. It immediately loses all access to your account and harnesses until you connect it again.
